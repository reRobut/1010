1. 调色盘（Color Palette）的微调：原版四色（橙绿蓝黄）
2. 形状与细节的微调：
    - 圆角弧度： 原版如果是 4px 圆角，你可以尝试大圆角（更像豆腐，更Q弹）或者超小圆角（更硬朗，更极客）
    - 材质感： 给方块加一点点极其微弱的渐变，或者一点点内阴影，让它看起来像玻璃、像陶瓷或者像塑料积木
    - 动画细节：消除动画
3. 背景色
```
const ColorPalette = [
    "#FF5733", // 0: 无
    "#33FF57", // 1: 绿
    "#3357FF", // 2: 蓝
    "#3357FF", // 3: 黄
    "#3357FF", // 4: 橙
];
```
