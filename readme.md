1. 调色盘（Color Palette）,背景色的微调：原版四色（橙绿蓝黄）
2. 形状与细节的微调：
    - 圆角弧度： 原版如果是 4px 圆角，你可以尝试大圆角（更像豆腐，更Q弹）或者超小圆角（更硬朗，更极客）
    - 材质感： 给方块加一点点极其微弱的渐变，或者一点点内阴影，让它看起来像玻璃、像陶瓷或者像塑料积木
3. 消除动画
4. 音效
